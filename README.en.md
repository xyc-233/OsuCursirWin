Windows global cursor overlay:

- Draws the cursor using a native click-through transparent window that follows the mouse.
- Temporarily hides the native Windows pointer with transparent system cursors.
- Supports rotation while dragging, scale/glow on press, and hover sound when hovering over clickable elements.
- Restores the original system cursor on exit.
- Sound effect support.


## Run

Download `OsuCursorWin-Setup-version-x64.exe`, run it, and approve the administrator prompt. The installer includes the .NET runtime, configures Start menu coverage, installs the application, and creates a Start menu shortcut, with an optional desktop shortcut. Normal launches and login startup do not require elevation. Run a newer installer to upgrade.

The portable `OsuCursorWin.exe` runs directly but requires .NET 8 Desktop Runtime and does not provide Start menu coverage.

Or run from source:

```powershell
dotnet run --project OsuCursorWin\OsuCursorWin.csproj
```

Requirements: Windows 10 version 1607 or newer, or Windows 11, on x64. Source runs and default portable builds require .NET 8 Desktop Runtime; the integrated installer includes it. User settings are retained after uninstall.

The settings window opens automatically on first launch and can be reopened from the tray menu. Changes take effect immediately and are saved to `%APPDATA%\OsuCursorWin\settings.json`. Minimizing or closing the settings window only hides it to the background instead of exiting the program.

Settings use Windows system colors and standard group boxes, checkboxes, sliders, and buttons, with keyboard navigation. Disabling a sound disables its volume control while retaining its value. Add `--settings` when starting the application to show settings immediately.

The Performance section provides an animation frame limit, rendering quality, and pausing continuous rendering while idle. Changes apply immediately and save automatically. Defaults follow the current display refresh rate, use high-quality rendering, and pause continuous rendering once animation settles. Lowering the frame limit affects rotation, scaling, and glow without delaying cursor position updates. The performance quality option uses faster image interpolation to reduce rendering work during rotation. The frame limit never exceeds the current display refresh rate.

The login startup option reflects the Windows startup entry's enabled state. Disabling it in Task Manager is reflected when settings reopen. Checking the option in the application enables the startup entry again.

Following system cursor visibility is enabled by default. When a game or application hides the Windows cursor, the overlay hides and stops triggering sounds. It returns when the system cursor becomes visible, without a game list. Visibility monitoring continues while hidden, and manually disabling the cursor from the tray takes precedence. A game that draws its own pointer without hiding the Windows cursor cannot be identified from this visibility signal alone.

Tap sound uses the embedded `OsuCursorWin\cursor-tap.wav` and plays on both press and release. Hover sound uses `OsuCursorWin\default-hover.wav` and plays when entering the hand cursor state, with a 20ms debounce. Audio uses a dedicated thread and a NAudio low-latency WaveOut channel pool; the UI thread only enqueues playback.

Normal `SetWindowPos` only changes ordering inside the desktop window band and cannot overlay immersive shell windows such as the Start menu. The optional UIAccess build supports those scenarios.

To enable `uiAccess`, the exe must be located in a secure directory such as `C:\Program Files\` and signed with a locally trusted certificate. The repository provides an installer script:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -UiAccess
powershell -ExecutionPolicy Bypass -File scripts\install-uiaccess.ps1
```

Run the installation script as administrator. It stops the current instance, reuses a valid local code-signing certificate (creating and trusting one if needed), copies the exe to `C:\Program Files\OsuCursorWin\`, and signs it. After that, launch `C:\Program Files\OsuCursorWin\OsuCursorWin.exe`.

The integrated installer handles these steps automatically and verifies the staged signature before replacing an existing installation. It uses a machine-level, non-exportable signing key associated with the installation directory. Upgrades reuse the certificate; uninstall removes installer-owned trust entries, application files, shortcuts, and matching startup entries in loaded user profiles. Personal settings and pre-existing certificates are retained.

The program receives low-level mouse events on a dedicated thread and moves the native transparent window immediately after processing each batch, without waiting for animation or WPF transparent-window synchronization. Cached images and a persistent bitmap buffer provide rotation, scale, and glow through Windows layered-window updates. A dedicated high-resolution timer follows the current monitor refresh rate, keeps at most one pending callback, and skips expired frames instead of building a backlog. Rendering stays active for 120ms after movement before stopping once animation settles. A single background worker performs edge hit testing and retains only the latest request, so a slow target window does not block cursor movement. Polling is used if hook installation fails.

All five mouse buttons are tracked independently. Input batching preserves button order, press locations, and quick out-and-back drags, while sustained input yields to rendering. Slider changes apply immediately and are saved together after 250ms of inactivity, or when the settings window closes. The overlay still passes through Windows desktop composition and cannot guarantee the latency of the native hardware cursor.

On a resizable window edge or corner, the cursor smoothly points toward the corresponding one of eight directions. Dragging to resize retains the original rotation effect, using the direction from the initial press point to the current position. Releasing on an edge restores that edge's orientation; leaving the edge restores the normal orientation. This works independently of sound settings. Window hit testing takes priority so internal splitters are not mistaken for outer edges.

Hovering over clickable buttons or links preserves the cursor's normal orientation while retaining hover glow and sound.

The overlay detects Windows taskbar thumbnail preview windows (`TaskListThumbnailWnd`) and temporarily raises the overlay above the preview window so the cursor is not hidden by taskbar previews.

## Build

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

The build outputs `publish\OsuCursorWin.exe`. It is a `win-x64` framework-dependent single-file build and requires .NET 8 Desktop Runtime.

The `-UiAccess` build outputs `publish-uiaccess\OsuCursorWin.exe` and must be signed through the installation script before running.

Building the integrated installer requires .NET 8 SDK and [Inno Setup 6](https://jrsoftware.org/isdl.php):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1 -Version 1.1.0
```

Distribute `artifacts\OsuCursorWin-Setup-1.1.0-x64.exe` as a single file. Use `-InnoSetupCompiler "C:\Tools\Inno Setup 6\ISCC.exe"` for a custom compiler location. Language resource attribution is in `installer\NOTICE.txt`. Build tools and local certificates or private keys are excluded from the installer.

If the Start menu covers the cursor, run `C:\Program Files\OsuCursorWin\OsuCursorWin.exe` instead of the portable executable under `publish`. Settings show whether Start menu coverage is enabled. Verify the actual Windows UIAccess permission without exiting the running instance with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\smoke.ps1 -ExePath "C:\Program Files\OsuCursorWin\OsuCursorWin.exe" -RequireUiAccess
```

## Validation

```powershell
powershell -ExecutionPolicy Bypass -File scripts\test.ps1
```

Regression checks cover multiple mouse buttons, quick drags, animation across refresh rates, native rendering and visibility, frame clock stop/restart, WPF rendering, settings persistence, audio conversion and asynchronous failure recovery, and recovery after cursor replacement failures. They also validate the manifest embedded in the built executable. The separate `--smoke` instance exits after 2.5 seconds without replacing system cursors, installing mouse hooks, saving settings, or changing startup registration.

Input regressions also check hook startup, shutdown, batching, and rendering fairness. Background edge detection checks cover slow queries, stale results, and cleanup. Run `dotnet run --project tests\LatencyProbe -c Release -- --rotate --input-hz 8000` to measure high-rate synthetic input through the application queue to window position submission, together with actual native rendering callback intervals and durations. It does not move the system pointer, and its results do not measure physical display latency. `tests\PerformanceProbe` provides a standalone transparent WPF window for comparison.

## Code Structure

`CursorModel` owns input and animation state, `CursorDimensions` centralizes sizing, `NativeCursorOverlay` owns the native window and rendering buffer, and `NativeFrameClock` schedules animation. `MainWindow` connects mouse events, window placement, the tray, and settings. `CursorVisual` remains for WPF comparison tests. The animation model can be tested independently of WPF and Win32.

`PcmSample` handles audio samples, `AudioVoice` owns each playback lifecycle, and `TapSoundPlayer` manages the bounded queue and worker thread. Shutdown waits at most 250ms for audio; delayed driver cleanup continues safely in the background.

## If the Cursor Is Not Restored

Normally, exiting from the tray restores the cursor automatically. If the program is force-killed and the system cursor remains transparent, run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\restore-cursor.ps1
```

## Notes

- Only Windows 10/11 is supported.
- Exclusive fullscreen games may not show the overlay; borderless or windowed mode is recommended.
- Cursor images come from the original `assets/cursor.png` and `assets/cursor-additive.png`.
- Hover sound requires application support and the effect is not very good. It is recommended to enable the "Play when stretching windows" option so the sound plays when the cursor is over a resizable window border.
